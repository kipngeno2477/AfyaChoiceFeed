# AfyaChoice Feeds Web Application

Official web platform for **Afyachoice Feeds** & **Nuscience Concentrates** (*Afyachicks Kenya Limited*).

> **"Better Feeds. Better Yield. — Partnering with Farmers for a Food Secure Kenya"**

---

## 🌟 Key Features

- **Brand Design & Visual Identity:**
  - High-impact agricultural branding in Forest Green (`#0b542c`) and Brand Orange (`#e86014`).
  - Joint **Afyachoice Feeds | Nuscience Concentrates** brand emblem in the navbar.
  - Smooth left-to-right animated contact marquee ticker with hotline (`0792 764 002`), WhatsApp consultation, live 24/7 mill dispatch status, and regional depots.
- **Dynamic Hero Section:**
  - Fast 3.5s smooth sliding transitions between master farm art, commercial poultry sacks, and warehouse dispatch.
  - Linear dark green gradient on the left side framing high-contrast headlines and CTAs.
  - Nutrition Partner Ribbon: *Increased Milk Production (+4L)*, *Healthy Animals*, *Greater Profitability*, *Sustainable Farming*.
- **Authentic Product Packaging Catalog (`AFYACHICK`):**
  - High-resolution 3D bag photos and pricing for commercial 50kg sacks:
    - **Poultry:** Chick Starter (0-4wks), Chick Grower (5-16wks), Developer Mash, Pre-Layer, and Layer 105/145/165/245.
    - **Pigs:** Babistar Creep Feed, Pig Grower (12-17wks), Starter/Fattener, Finisher Feeds, Gestation Feed, and Concentrates.
    - **Dairy:** Dairy Meal (High Yield Formula) and Dairy Calf Starter.
    - **Nuscience Concentrates:** 5% and 25% mixing formulas.
- **Protected Administrator Management Portal:**
  - Discrete access via footer link (*Staff & Admin Portal*) and customer modal (*Store Management & Admin Sign In*).
  - Admin authentication gate with **Sign In** and **Register Admin** tabs (protected by security passcode `AFYA2026`).
  - Active session indicator and `👑 Admin Dashboard` badge in the navbar for logged-in administrators.
  - Real-time catalog manager to add, delete, and inspect feed products.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd AfyaChoice
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
